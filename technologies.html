Technologies

What this project is built with, and what each technology is responsible for.

HTML5

Provides the structure and content of every page in this portal.

Page structure Semantic elements Forms Input types Validation

CSS3

Handles the custom visual styling layered on top of Bootstrap, kept in one shared stylesheet.

Custom styling Spacing Colors Responsive adjustments Transitions

Bootstrap 5

The main framework this project is built on, providing layout and ready-made components.

Responsive grid Navbar Cards Buttons Forms Tables Badges

JavaScript

Used only minimally, for frontend interaction — it is not one of the primary technologies specified for this project. It powers the registration form's demo submit/reset feedback and highlights the active navigation link.

Form submit feedback Reset behavior Active nav state
This is a frontend-only project: no backend, database, or server-side language is used anywhere in this portal.
