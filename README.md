# Healthcare Appointment & Patient Portal

## Overview

The Healthcare Appointment & Patient Portal is a responsive frontend web application designed to provide a simple interface for patient registration, appointment information, and health information management.

The project demonstrates the use of HTML5, CSS3, and Bootstrap5 to create a structured, responsive, and user-friendly healthcare portal.

## Features

- Responsive navigation bar
- Patient Registration Form
- Patient personal information fields
- Department and doctor selection
- Appointment date and time selection
- Symptoms / Health Concern field
- HTML5 form validation
- Register and Reset buttons
- Bootstrap cards for different sections
- Appointment information table
- Health Information section
- Services section
- Technologies section
- Responsive layout for desktop, tablet, and mobile devices
